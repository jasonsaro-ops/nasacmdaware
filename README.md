# NASA Mission Control

Single-monitor Mission Control console inspired by Territory Studio / *The Martian* UI.

## Design
- Cyan/teal technical panels, dark backgrounds, FEED labels
- White **NASA** wordmark in Helvetica
- Dense layout for one monitor
- Clickable panels open **draggable floating windows** (always on top)

## Features
- **ISS track** — solid red past path + dashed red future (~90 min)
- **NEO globe** — rotating Earth-in-space canvas; markers clickable
- APOD, EPIC, DONKI, EONET, Mission Digest, JPL, Live cameras
- SOL-style alert ping (Martian day-change chime)

## Deploy
Push to GitHub Pages or open `index.html` locally.
